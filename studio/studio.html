        Connections
        
    
        Everything in the Studio works without a connection. Connect when you want a slider moved here to move in Blender, Godot, Unreal or RICO at the same time, or to send shaders to another Studio.
        
    
        
      
        Start the bridge on this computer. In the inoscula folder, double-click Live Link.bat (or Live Link Shared.bat to let other computers join). Without the .bat files, run:
        
        node bin/inoscula-live.ts
        Leave that window open. Ports: 9420 for Studios and web pages, 9421 Blender, 9422 Godot, 9000 OSC out, 9419 changes coming in.
        
      
        Blender. Build the material first (Blender tab, Run Script). Then Edit, Preferences, Add-ons, Install from Disk, pick importers/inoscula_live_blender.py and tick it. Every Inoscula material in the open file follows the link both ways.
        
      
        Godot. Use the Godot export as a ShaderMaterial, then add importers/inoscula_live.gd to any node in the scene. It is a tool script, so the link works in the editor and while the game runs.
        
      
        Unreal. Turn on the Remote Control API plugin, run the Inoscula script with your object selected (it makes the Material Instance MI_[Name]), and start the bridge with its path, from a Command Prompt in the inoscula folder:
        
        "Live Link.bat" --unreal http://localhost:30010 --unreal-instance /Game/Inoscula/MI_[Name]
        
      
        RICO Engine, or anything that speaks OSC, receives /inoscula/[shader]/[parameter] on port 9000. Change it with --osc [port].
        
      
        Another computer. On the computer running the bridge, start it with --share --key [a pass word]. It prints an address such as ws://192.168.1.20:9420. Type that address and the pass word below on the other computer.

        Import a shader or graph
        
    
        Paste a .inoscula.json: the one the Blender importer writes (blender_to_inoscula.py), the one Unreal writes (inoscula_from_unreal.py), or one from Godot (inoscula-pull). It opens as code, with every change made in that program.
        A GLSL or HLSL shader works here too: one from Shadertoy, The Book of Shaders, three.js or TouchDesigner, a Unity .shader, or the code from an Unreal Custom node. You can also paste one straight into the code editor.

        Inoscula code reference
        
    
        name "My Shader";
shading "lit";                    leave out for unlit (the same color everywhere)

uniform float speed = 1.0;   // @range 0 4 @label Speed
uniform vec3  tint = vec3(1.0, 0.4, 0.2); // @color @label Tint
uniform float bands = 4.0;   // @range 1 8 @step 1 @label Bands       whole numbers
uniform float glow = 1.0;    // @toggle @label Glow                   a switch: 0 or 1
uniform float mode = 0.0;    // @options Soft | Hard | Off            a list: 0, 1, 2
uniform float edge = 0.2;    // @range 0 1 @group Edges @desc How wide the edge is
                                           parameters: controls in every tool, animatable there
                                           (keyframes, Sequencer, AnimationPlayer). @group makes a
                                           section, @desc a tooltip. + Add parameter writes these.

float bands(float x, float n) {           your own functions; copied in where used
  return floor(x * n) / n;
}

void main() {
  float x = ...;  vec3 v = ...;            variables, reassign freely
  color = ...;                              unlit: the final color. lit: the base color
  alpha = ...;                              optional, 0 to 1
  roughness = ...;  metallic = ...;         lit only
  bump = ...;                               lit: height in meters (a few millimeters is plenty)
  emission = ...;                           lit: glow, linear RGB
  coat = ...;  coat_roughness = ...;        lit layers (clear coat)
  sheen = ...;  sheen_color = ...;  sheen_roughness = ...;
  subsurface = ...;
}

INPUTS        uv  object_pos  object_normal  world_pos  normal  view_dir  time
              light_dir  light_color        the lighting contract
              curvature  occlusion          shape data, from Prepare model
CONSTANTS     PI  TAU
MATHS         + - * /   sin cos abs floor fract exp sqrt pow min max clamp mix
              smoothstep step saturate mod sign one_minus radians atan(y, x)
VECTORS       vec3(x, y, z)  vec3(x)  v.x v.y v.z (or .r .g .b)  dot length
              normalize distance reflect
COMPARE       a > b   a < b   a >= b   a <= b    give 1.0 or 0.0
PICK          condition ? a : b
PATTERNS      noise(p, scale, detail, roughness, lacunarity)   Blender's Noise Texture
              voronoi(p, scale, randomness)  distance; .color per cell; .position
              hash(p)       a random 0..1 per point, Blender's White Noise
              ramp(t, "constant" or "linear", 0.0, vec3(...), 0.5, vec3(...), ...)

Not allowed: loops and if blocks. Node graphs cannot loop, so a shader with
loops could not travel. Use mix, step, smoothstep or ?: instead.

Stop motion: float frame = floor(time * 12.0);  then use frame in hash() or
noise() so the surface changes 12 times a second, like a puppet between shots.
